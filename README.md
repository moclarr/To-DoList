# ✅ To-Do List | Gerenciador de Tarefas

Projeto de lista de tarefas desenvolvido utilizando **HTML, CSS e JavaScript**, com foco na manipulação do DOM e armazenamento de dados no navegador.

---

## 🚀 Funcionalidades

- Adição de tarefas  
- Remoção de tarefas  
- Marcação de tarefas como concluídas (checkbox)  
- Atualização dinâmica da interface (DOM)  
- Persistência de dados com **Local Storage**  

---

## 💻 Tecnologias utilizadas

- HTML  
- CSS  
- JavaScript  

---

## 🧠 Conceitos aplicados

- Manipulação do **DOM**  
- Eventos em JavaScript  
- Validação de dados  
- Uso de **Local Storage** para persistência  
- Atualização dinâmica da interface  

---

## ⚙️ Funcionamento

As tarefas são armazenadas no **Local Storage** do navegador, permitindo que os dados sejam mantidos mesmo após atualizar a página.

Ao carregar a aplicação, os dados são recuperados do armazenamento e renderizados na interface. As tarefas podem ser adicionadas, marcadas como concluídas ou removidas, sendo automaticamente atualizadas tanto na interface quanto no armazenamento local.
